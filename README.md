## 📖 Overview

This application manages the complete movie ticket booking journey — from selecting a show and checking seat availability, to calculating cost, approval, confirmation, and sending a booking notification.

---

## 🔄 Case Flow

| Stage | What Happens |
|---|---|
| 🎟️ **Booking Request** | Submit movie, show, and ticket details |
| 📊 **Availability** | Check seat availability & calculate total cost |
| ✅ **Booking Confirmation** | Approve and confirm the booking |
| 🎫 **Booking Execution** | Assign seats/ticket & route by show type |
| 📧 **Notification** | Send booking confirmation to customer |

---

## ✨ Key Features

- 💰 Automatic ticket price and total cost calculation
- 🪑 Seat availability validation
- 🔀 Decision table–based routing (Premium / Standard queues)
- 📬 Automated confirmation notifications
- ⏱️ SLA-tracked case resolution
